# TayoBuild

**TayoBuild** is a web platform for construction and skilled services, designed to help customers explore available services, view completed projects, check service locations, learn more about the business, and submit service inquiries.

🌐 **Live Website:** https://tayobuild-solutions.netlify.app/

## Features

- Responsive landing page
- Home section
- About section
- Services section
- Project showcase
- Locations section
- Contact section
- Responsive navigation
- Mobile-friendly layout
- Interactive UI elements
- Contact and review forms

## Technologies

- **React** – Frontend development
- **JavaScript** – Functionality and interactions
- **Tailwind CSS** – Styling and responsive layouts
- **Vite** – Development and build tool
- **Figma** – UI/UX design and prototyping
- **Visual Studio Code** – Development

## Project Purpose

TayoBuild was developed to provide a modern and accessible web platform for a construction and skilled-services business. It allows customers to:

- Browse available services
- View completed projects
- Check service locations
- Learn more about the business
- Submit service inquiries
- Share feedback through the review form

## Design

The website was designed in **Figma** before development. The design focuses on clean presentation, simple navigation, clear content sections, and responsive behavior across desktop and mobile devices.

## Development

The frontend was developed using **React, JavaScript, Tailwind CSS, and Vite**.

The project uses reusable React components and responsive layouts to organize the website's services, projects, locations, company information, contact features, and review functionality.
