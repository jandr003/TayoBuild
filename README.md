TayoBuild is a web-based platform for a construction and skilled-services business, allowing customers to explore services, view completed projects, check service locations, and submit inquiries and feedback.

The website features a responsive interface designed to present business information clearly and help customers navigate the available services.

## Features

### Business Information
- Home section
- About section
- Services section
- Project showcase
- Service locations
- Contact information

### Customer Inquiries and Feedback
- Contact form for service inquiries
- Review form for customer feedback

### User Interface
- Responsive navigation
- Mobile-friendly layouts
- Reusable React components
- Interactive UI elements
- Consistent styling across sections

## Responsive Design

TayoBuild adapts to desktop, tablet, and mobile screen sizes through flexible layouts and responsive components. Navigation, service listings, project cards, and contact sections are designed to remain accessible and organized across different devices.

## Project Purpose

TayoBuild provides customers with a convenient way to learn about a construction and skilled-services business, explore its services and projects, check service locations, and get in touch through its inquiry and feedback forms.

## Design

The website was designed in Figma before development to establish its layout, visual direction, and user flow. The final implementation translates the design into a responsive website with consistent styling and clearly organized content.
