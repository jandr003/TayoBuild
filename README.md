# TayoBuild

A modern construction services website that connects homeowners with trusted builders and skilled professionals for repairs, renovations, and home improvement projects.

## Features

- Responsive Landing Page
- Hero Section
- About Section
- Services Section
- Project Showcase
- Contact Form
- Mobile-Friendly Design

## Technologies

- React
- JavaScript
- Tailwind CSS
- Vite
- Visual Studio Code
- Figma

## Requirements

- Node.js 18+
- npm
- Modern Web Browser
