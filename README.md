With direct inquiry and feedback forms, customers can quickly explore what TayoBuild offers and get in touch with the business.

## Project Purpose

TayoBuild was developed as a web platform for a construction and skilled-services business. The website provides customers with a straightforward way to:

* Browse available services
* View completed projects
* Check service locations
* Learn more about the business
* Submit service inquiries
* Share feedback through the review form

## Design

The website was designed in Figma before development to establish the overall structure, visual direction, and user flow. The design uses a clean and organized interface with clear sections and consistent styling throughout the website. The content structure was planned around the business's key information, including its services, completed projects, service locations, and contact details. This approach keeps the website easy to understand while allowing users to quickly find the information they need.

## Responsive Design

TayoBuild features a responsive interface optimized for desktop and mobile devices. The website adjusts its navigation, content sections, cards, images, buttons, and typography according to the available screen space while maintaining a clear and consistent presentation. The responsive implementation ensures that key sections, including services, projects, locations, and contact information, remain accessible and well-organized across different screen sizes.

## Development

The frontend was developed using React, JavaScript, Tailwind CSS, Vite, and Lucide React. Reusable React components were used to structure the different sections of the website, while Tailwind CSS was used to implement the visual design and responsive behavior. Lucide React was used for the interface icons throughout the website.
