# TayoBuild

**TayoBuild** is a web platform for a construction and skilled-services business. It allows customers to explore available services, view completed projects, check service locations, learn more about the business, and submit inquiries or feedback.

### 🌐 Live Demo

[Visit TayoBuild](https://tayobuild-solutions.netlify.app/)

## Features

* Responsive landing page
* Home section
* About section
* Services section
* Project showcase
* Locations section
* Contact section
* Responsive navigation
* Mobile-friendly layout
* Interactive UI elements
* Contact and review forms

## Project Purpose

TayoBuild was developed as a modern web platform for a construction and skilled-services business. The website provides customers with an easy way to:

* Browse available services
* View completed projects
* Check service locations
* Learn more about the business
* Submit service inquiries
* Share feedback through the review form

## Design

The website was designed in **Figma** before development. The design focuses on a clean and organized layout, clear content sections, straightforward navigation, and responsive behavior across desktop and mobile devices.

## Development

The frontend was built using **React, JavaScript, Tailwind CSS, and Vite**. The project uses reusable React components and responsive layouts to keep the website organized and consistent across its different sections.
